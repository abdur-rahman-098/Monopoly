## 1. The Game Name

### Naming Direction

The name should feel:
- **Powerful** — this is a game about dominance, wealth, and survival
- **Urban** — rooted in the city, in real estate, in property
- **Sophisticated** — one or two words maximum, no puns or wordplay
- **Original** — no reference to Monopoly or any existing property game

### Recommended Name Concepts

| Name | Feeling | Rationale |
|---|---|---|
| **DOMINION** | Power, control, empire | You don't buy property — you claim dominion over a city |
| **BOROUGH** | London-rooted, authoritative | A borough is a London administrative district — grounded and specific |
| **ESTATE** | Luxury, real estate, legacy | Clean, premium, directly describes the game's world |
| **QUARTER** | Urban, architectural, London | The city is carved into quarters — you fight for yours |
| **LEDGER** | Finance, strategy, records | Every transaction recorded — cold, precise, premium |
| **LANDMARK** | London, prestige, permanence | Properties as landmarks — ownership as legacy |
| **THE CITY** | London-specific, financial | "The City" is London's financial district — loaded with meaning |
| **PRECINCT** | Urban, territorial, modern | Territory-based — you control precincts, not just properties |

### Top Recommendation

> **BOROUGH**

It is London-specific without being derivative, sophisticated without being obscure, and carries the right weight for a dark premium property game. It also works visually — short, strong, typographically bold.

**Runner-up:** DOMINION — if the desired feeling leans more toward empire-building power than London specificity.

> ✅ Select a name before proceeding to any visual asset creation.

## 2. World & Theme

### The World

The game is set in a **modern, ultra-premium version of London** — a city where old money and new ambition collide. The streets are the real ones: Mayfair, Park Lane, Trafalgar Square. But the world is heightened — darker, more cinematic, more architectural.

This is not tourist London. This is:

- **Boardroom London** — glass towers, financial districts, private clubs
- **Late-night London** — city lights reflecting on wet streets
- **Power London** — where deals are made, fortunes built, empires lost

### The Player's Role

Players are **property magnates and dealmakers** — not casual buyers. Every decision carries weight. Every trade is a negotiation between rivals. The tone should reflect that this is a game of **strategy, ambition, and survival**.

### The Emotional Arc

| Game Stage | Feeling |
|---|---|
| Early game | Opportunity — the city is open, everything is for sale |
| Mid game | Tension — alliances form, the board fills up, trades get serious |
| Late game | Pressure — cash tightens, rents spike, one wrong move ends you |
| End game | Dominance — the last player standing claims the city |

## 5. Typography Direction

### Typeface Philosophy

Two typefaces only. Everything else is a variation of weight and size within those two.

### Display / Headings — Recommended: A Modern Geometric Sans

**Character:** Architectural. Precise. Authoritative.

Qualities to look for:
- Geometric construction (not humanist)
- Wide range of weights (Light through Black)
- Strong at large sizes
- Excellent letter spacing at display scale
- Clean numerals

**Candidates:** Neue Haas Grotesk · Aktiv Grotesk · F37 Bolton · Monument Grotesk

### Body / UI — Recommended: A Refined Mono or Tabular Sans

**Character:** Technical. Precise. Financial.

Qualities to look for:
- Tabular numerals (critical for cash amounts and rent tables)
- Clean at small sizes
- Feels slightly editorial or financial — not casual
- Pairs confidently with the display face

**Candidates:** IBM Plex Mono · Söhne Mono · DM Mono · Martian Mono

### Typography Scale

| Role | Size | Weight | Usage |
|---|---|---|---|
| Display | 48–72px | Black / 900 | Game name, victory screen |
| H1 | 32px | Bold / 700 | Screen titles |
| H2 | 24px | SemiBold / 600 | Section headings |
| H3 | 18px | SemiBold / 600 | Panel headings |
| Body | 14–15px | Regular / 400 | Descriptions, rules text |
| Caption | 11–12px | Regular / 400 | Labels, metadata, hints |
| Currency Display | 28–40px | Bold / 700 | Cash totals, rent amounts |
| Numeric Display | 48px | Black / 900 | Dice totals, large counts |

### Typography Rules

- **Letter spacing:** Headings and labels use `+0.05em` to `+0.12em` tracking — controlled and architectural
- **Line height:** Body text at `1.6` — generous and readable on dark backgrounds
- **All caps:** Used selectively for labels, player names, and section identifiers — not for body copy
- **Currency amounts** always use the monospaced face for alignment

## 6. Board Aesthetic

### Overall Board Feel

The board is a **dark architectural city map** — not a bright game board. It should feel like a premium physical product: laser-etched, considered, beautifully gridded.

### Board Surface

- **Background:** Deep obsidian (`#0D0D14`) with a very subtle texture — think brushed dark metal or matte lacquered wood
- **Grid lines:** Fine gold (`#C9A84C` at ~15% opacity) — barely visible, creating structure without noise
- **Corner spaces** (GO, Jail, Free Parking, Go To Jail): Larger tiles with strong architectural treatment

### Property Tiles

Each property tile should contain:

| Element | Treatment |
|---|---|
| Colour band | Full-width strip at the top (or outer edge) in the group colour |
| Property name | Clean sans-serif, ivory, all caps, small tracking |
| Price | Bottom of tile, monospaced, gold |
| Ownership indicator | Subtle fill tint or player-colour border when owned |
| Building indicators | Small architectural icons — houses as outline squares, hotel as filled square |
| Mortgage indicator | Diagonal line or desaturated overlay across the tile |

### Corner Spaces

| Space | Visual Direction |
|---|---|
| **GO** | Gold arrow, clean typographic treatment, "$200" clearly visible |
| **Jail / Just Visiting** | Split tile — cool blue for visiting, red for incarcerated |
| **Free Parking** | Minimal — parking icon, muted, clearly "nothing happens" |
| **Go To Jail** | Strong red accent, directional arrow |

### Special Spaces

| Space | Visual Direction |
|---|---|
| Chance | A distinctive mark/icon in the game's card colour system |
| Community Chest | A second distinctive mark — clearly different from Chance |
| Income Tax / Super Tax | Clean financial treatment — numbers prominent |
| Stations | Architectural icon — minimal, geometric |
| Utilities | Simple icon system — lightning bolt and water drop, refined |

### Board Atmosphere

- The board should look **dramatically different at night vs a typical Monopoly board**
- When lit by player tokens and owned colour bands, the board should feel alive and dynamic
- Owned properties glow subtly with their group colour
- The board rewards looking at it — dense with information but never cluttered

## 7. Token Concepts

### Design Direction

Tokens are **luxury lifestyle objects** — small, beautifully detailed, three-dimensional in appearance. Each token represents a different facet of wealth and ambition in the city.

### Recommended Token Set (8 tokens for up to 4 players to choose from)

| Token | Object | Visual Character |
|---|---|---|
| **The Key** | A luxury property key / architectural key | Timeless — you own the city |
| **The Watch** | A precision mechanical watch face | Success measured in time and money |
| **The Penthouse** | A sleek glass tower / top-floor silhouette | The ultimate acquisition |
| **The Yacht** | A minimal luxury vessel | Freedom, escape, wealth |
| **The Briefcase** | A slim, architectural attaché case | The dealmaker |
| **The Ring** | A signet ring — old money, authority | Power passed down |
| **The Car** | A minimal luxury saloon — one elegant line | Speed, status, momentum |
| **The Crown** | An architectural crown — not royal kitsch | Dominance, the winner's symbol |

### Token Rendering

- Tokens should appear **isometric or gently three-dimensional** on the board
- Each token is rendered in the **player's assigned colour** with gold accents
- Tokens should be **immediately distinguishable** from one another at small sizes on the board
- When multiple tokens share a space, they arrange neatly — slightly overlapping like playing cards

## 9. Card Style & Illustration Direction

### Chance & Community Chest Equivalents

These should be **renamed** as part of the original game identity.

### Recommended Name Replacements

| Original | Suggested Replacement | Rationale |
|---|---|---|
| **Chance** | **RISK** | Clean, single word, thematically perfect |
| **Community Chest** | **THE CITY** | Ties the community pot to London's identity |

### Card Design — Luxury Magazine Spread Feel

Cards should feel like **editorial inserts from a premium financial or lifestyle magazine** — not cartoon game cards.

### Card Structure

```
┌─────────────────────────────────┐
│                                 │
│        RISK                     │  ← Card type (large, tracked caps)
│                                 │
│  ─────────────────────────────  │
│                                 │
│  [Full-bleed abstract image /   │
│   bold typographic composition] │
│                                 │
│  ─────────────────────────────  │
│                                 │
│  Advance to Trafalgar Square.   │  ← Card instruction text
│  If you pass GO, collect $200.  │
│                                 │
│                            ►    │  ← Direction indicator
└─────────────────────────────────┘
```

### Card Visual Language

| Element | Treatment |
|---|---|
| Background | Deep slate (`#1E1E30`) |
| Card type label | Gold, tracked, all caps — top left |
| Illustration zone | Abstract photography or bold typographic art |
| Instruction text | Ivory, body typeface, generous line height |
| Borders | Hairline gold border — 1px, full perimeter |
| Back of card | Geometric gold pattern on obsidian — distinctive per deck |

### Card Back Design

- **RISK cards:** A geometric lattice pattern in gold on obsidian — angular, sharp
- **THE CITY cards:** A circular mandala-like pattern — community, interconnection

The two backs must be **immediately distinguishable** at a glance.

## 10. Buildings — Houses & Hotels

### Design Direction

Buildings should feel **architectural** — not toy-like plastic houses. They are miniature representations of real development.

### Houses

| Element | Treatment |
|---|---|
| Form | Clean isometric cube / residential block — not a cartoon house shape |
| Colour | Ivory/white with gold trim |
| Size on board | Small but clearly readable |
| Count display | 1–4 individual building icons on the property tile |

### Hotels

| Element | Treatment |
|---|---|
| Form | Taller isometric tower — clearly differentiated from houses |
| Colour | Gold — the hotel is the pinnacle of development |
| Size on board | Larger than a house — dominates the tile |
| Count display | Single prominent icon on the property tile |

### Building Animation

- Houses **appear with a brief upward build animation** — like construction
- The hotel upgrade shows **4 houses merging into 1 tower** — a distinct transformation sequence

## 11. Currency Design

### The Game's Currency

The currency should feel like a **premium private bank note** — not Monopoly money.

### Design Elements

| Element | Treatment |
|---|---|
| Denomination | Displayed large, prominently, in the monospaced typeface |
| Colour | Each denomination gets a distinct dark tone — not garish |
| Texture | Subtle security-print style pattern in the background |
| Marking | Game name / logo watermarked subtly |
| Size | Consistent proportions — designed as a system |

### In-Game Currency Display

Physical currency design is for physical/print reference. In the digital game:

- Cash amounts displayed in **gold monospaced numerals**
- Always prefixed with `$`
- Large balances use comma formatting: `$1,500` not `$1500`
- Negative changes shown in **danger red** with a `−` prefix
- Positive changes shown in **success green** with a `+` prefix

## 12. Iconography

### Icon Style

All icons should be:

- **Line-based** — outline style, not filled
- **Geometric** — consistent stroke width, precision
- **Minimal** — each icon reduced to its essential form
- **Gold on dark** — primary usage

### Core Icon Set

| Icon | Usage |
|---|---|
| House (outline square) | Building — 1 house |
| Hotel (outline tower) | Building — hotel |
| Mortgage (diagonal line through square) | Mortgaged state |
| Lightning bolt | Electric Company |
| Water drop | Water Works |
| Train | Station spaces |
| Dollar sign | Financial actions |
| Lock | Locked / unavailable |
| Handshake | Trade |
| Dice | Roll action |
| Person / token silhouette | Player presence |
| Crown | Winner / victory |
| Jail bars | Jail state |
| Arrow right | Movement / direction |
| Refresh | Roll again / reroll |

### Icon Rules

- Icons are **never used alone** at first introduction — always paired with a text label
- At familiar contexts (after onboarding), icons can stand alone with tooltips
- All icons share a **24×24px base grid**
- Minimum touch/click target: **44×44px**

## 13. Motion & Animation Language

### The Principle

> Every animation has a job. If it doesn't communicate state or guide attention, it doesn't ship.

### Easing Philosophy

| Type | Easing | Usage |
|---|---|---|
| Entrances | `cubic-bezier(0.0, 0.0, 0.2, 1.0)` — ease out | Elements coming into view |
| Exits | `cubic-bezier(0.4, 0.0, 1.0, 1.0)` — ease in | Elements leaving view |
| State changes | `cubic-bezier(0.4, 0.0, 0.2, 1.0)` — ease in-out | Value updates, ownership changes |
| Celebrations | Spring physics | Victory, hotel upgrade |

### Duration Scale

| Duration | Usage |
|---|---|
| `80ms` | Micro-interactions — hover states, button presses |
| `150ms` | UI transitions — panel opens, tab switches |
| `300ms` | Standard animations — card reveals, ownership changes |
| `500ms` | Token movement per space |
| `800ms` | Major events — bankruptcy, trade completion |
| `1200ms+` | Victory sequence only |

### Signature Animations

| Event | Animation Description |
|---|---|
| **Dice roll** | Dice tumble with physics — settle to final face |
| **Token movement** | Token lifts slightly, hops space-by-space, lands with a subtle impact |
| **Property purchase** | Colour band floods in from the player's direction |
| **Rent collection** | Gold coin / number lifts from payer, arcs to receiver |
| **House placed** | Building rises from the tile — upward construction |
| **Hotel upgrade** | 4 houses compress and transform into 1 tower — impactful |
| **Card reveal** | Card flips in from the deck — physical card flip motion |
| **Trade complete** | Property cards slide across the negotiation table |
| **Bankruptcy** | Properties drain of colour — returning to the Bank's neutral grey |
| **Victory** | Gold particles, board dims, winner's panel expands — full cinematic moment |

## 14. UI Personality

### The Interface Voice

The UI should speak like a **premium financial product or architectural firm** — not like a game app.

### Tone of Copy

| ❌ Avoid | ✅ Use Instead |
|---|---|
| "Oops! You can't do that!" | "This property cannot be traded." |
| "Awesome! You bought it!" | "Food Street. Acquired." |
| "Uh oh, you're in jail!" | "Sent to Jail." |
| "You win!! 🎉🎉🎉" | "BOROUGH. Player 2." |
| "Are you sure you want to do this?" | "Confirm restart. This cannot be undone." |

### UI Moments

| Moment | Copy Direction |
|---|---|
| Property purchased | `[PROPERTY NAME]. Acquired.` |
| Rent charged | `Rent due. $[AMOUNT] to [OWNER].` |
| 6+6 rolled | `Double Six. Roll again.` |
| Sent to jail | `Sent to Jail.` |
| Bankruptcy | `[PLAYER NAME]. Eliminated.` |
| Victory | `[PLAYER NAME]. Last standing.` |
| Trade proposed | `Trade proposed by [PLAYER NAME].` |
| Trade accepted | `Trade agreed.` |
| Trade declined | `Trade declined.` |

### Panel & Modal Style

- Panels slide in from edges — never pop or bounce
- Modals appear with a **fade + subtle scale** — `scale(0.97)` to `scale(1.0)`
- Confirmation dialogues are **brief and precise** — no paragraphs
- Destructive actions (restart, quit) use **danger red** for the confirm button only

## 15. What This Game Is Not

To keep all creative decisions aligned, this section defines hard boundaries.

### Visual Boundaries

| ❌ This game is NOT | ✅ This game IS |
|---|---|
| Bright, colourful, family-friendly | Dark, premium, sophisticated |
| A Monopoly reskin | An original game with original identity |
| Cartoonish or playful in a childlike way | Playful in a *high-stakes adult* way |
| Flat and minimal to the point of being cold | Warm with depth — materials, texture, light |
| Neon or cyberpunk | London noir — dark, architectural, real |
| Casino or gambling aesthetic | Strategy and finance aesthetic |
| Generic SaaS dashboard | Premium game product |

### Tone Boundaries

| ❌ NOT | ✅ YES |
|---|---|
| Cute | Confident |
| Cheerful | Assured |
| Casual | Precise |
| Loud | Commanding |
| Frantic | Controlled |
